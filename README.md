
# GTA VEHICLE STUDIO

A browser-based GTA vehicle photography platform.

## Features

- Vehicle image upload
- Drag and drop support
- Studio background selection
- Transparent PNG support
- PNG export
- Browser-based processing

## Supported Images

- PNG
- JPG / JPEG
- WEBP

## Technology

- HTML
- CSS
- JavaScript
- HTML Canvas API

## Hosting

GitHub Pages

## Development Roadmap

- Phase 1: Website foundation
- Phase 2: AI background removal
- Phase 3: Advanced studio environments
- Phase 4: GTA 3D vehicle rendering
- Phase 5: HD export and optimization
